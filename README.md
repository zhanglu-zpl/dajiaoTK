# 大角几何 · 初中几何题库

这是一个面向 2-3 人共用的轻量本地几何题库。它把收集到的几何资料按“图形入口 + 解题动作”重新整理，直接展示 PDF 中的原题页和图形，适合课堂备课、错题复盘和考前快速检索。

## 使用方式

直接双击 `index.html` 即可打开；也可以在当前目录启动一个本地静态服务器：

```powershell
python -m http.server 5173
```

然后访问 `http://localhost:5173`。

由于原始 PDF 是本机文件，浏览器可能禁止网页直接读取 `D:/办公/...` 路径。打开某份资料后，点击“选择本地 PDF”即可把对应文件载入阅读器；浏览器会记住最近的使用方式。若本机浏览器允许，也可以点击“尝试打开原文件”。

## 当前题库内容

首批已整理 14 道题，均来自《2024版 初中〈几何辅助线〉：辅助线作法综合练》。每道题保留原题页图像，并匹配该练习册中已核对的对应解析页；点击题卡即可在题目与解析之间切换。原 PDF 为扫描版，后续资料会按“可核对的题目页 + 解析页”逐批补入，避免不可靠的自动文字识别造成题目或答案错配。

## 分类逻辑

题型分类栏（左侧）共 9 个入口，除了按知识点划分的学科题型外，还有两个“跨学科”入口：

- 综合模型：最值、动点、考前六类模型
- 手写笔记模型：把《中考几何满分冲刺-手写笔记》里已整理的模型页单独作为一个题型入口，按模型名检索
  （如“费马点”“托勒密定理”“将军饮马”）。同一个模型会同时出现在它的学科题型下，方便两种找题方式切换。

学科题型：

- 点与线：共线、平行、垂直
- 角：角平分线、补角、倍角
- 三角形：全等、相似、三线
- 四边形：平行四边形、特殊四边形、梯形
- 圆：圆的基本性质、切线、共圆
- 辅助线：平移补形、旋转、延长截长补短
- 综合模型：最值、动点、考前六类模型

原始 PDF 不复制到项目目录，避免重复占用数 GB 磁盘；网页保存的是用于题库展示的原题页和解析页图像，并保留原书资料入口。
